# 자기 도메인 업무 분해 예시

- **과정:** AIFFEL 온보딩
- **도메인:** AI 기반 콘텐츠 제작 업무 자동화
- **과제 주제:** 콘텐츠 파일명 변경 및 폴더 자동 분류

## [도메인 맥락]

나는 **AI 자동화 시스템 설계·개발 0년 차 학습자**이며, AI 도구를 활용한 콘텐츠 제작 경험이 있다. 1인 크리에이터와 소규모 사업자의 반복 업무를 자동화하는 시스템을 개발하고 싶다. 특히 콘텐츠 제작 과정에서 영상·이미지·음성 파일의 이름을 변경하고 폴더별로 정리하는 반복 작업을 자동화하고자 한다.

## [네 동작 분석]

### 1. 분해 (Decomposition)

파일 목록 조회 → 확장자 확인 → 파일 유형 분류 → 파일명 변경 → 폴더 이동 → 결과 확인의 단계로 나눈다.

### 2. 패턴 인식 (Pattern Recognition)

영상(.mp4, .mov), 이미지(.jpg, .png), 음성(.mp3, .wav)처럼 확장자에 따라 파일 유형이 구분된다. 동일한 프로젝트에는 공통 프로젝트명과 순번을 적용할 수 있다.

### 3. 추상화 (Abstraction)

파일의 세부 내용과 관계없이 프로젝트명·확장자·유형·순번만 추출한다.

- **이름 규칙:** 프로젝트명_유형_순번.확장자
- **저장 위치:** 프로젝트명/파일유형/
- **예외 규칙:** 중복 이름 및 미지원 형식은 원본을 보존하고 별도 기록한다.

### 4. 알고리즘 (Algorithm)

1. 정리할 폴더와 프로젝트명을 입력한다.
2. 파일 목록과 확장자를 읽는다.
3. 확장자에 따라 파일 유형을 결정한다.
4. 새 파일명과 저장 위치를 생성한다.
5. 중복 여부를 확인한다.
6. 파일을 변경된 이름으로 지정된 폴더에 이동한다.
7. 예외 파일을 보존하고 처리 결과를 기록한다.

## [출력 요구]

**한국어 Markdown(.md) 문서**로 다음 결과물을 작성한다.

- 파일 정리 자동화 워크플로
- 파일 유형별 분류 및 이름 변경 규칙표
- 파일명 변경 전후 예시 3개
- Python 구현을 위한 단계별 알고리즘
- 예외 처리 방법과 검증 체크리스트

## [검증 기준]

- **검증자:** 실제 콘텐츠를 제작하고 파일을 관리하는 본인(1인 크리에이터)
- **검증 방법:** 영상·이미지·음성·예외 사례를 포함한 테스트 파일 10개를 준비하여 자동화 결과를 직접 비교한다.

**합격 기준**

1. 지원 대상 파일이 모두 지정된 유형별 폴더에 정확히 분류될 것
2. 파일명이 정해진 명명 규칙과 일치할 것
3. 파일 10개 모두 누락·손상 없이 보존될 것
4. 파일명 중복이나 미지원 형식 발생 시 원본을 덮어쓰거나 삭제하지 않을 것
5. 처리 전후 파일명·저장 위치·오류 여부를 확인할 수 있을 것
6. 본인이 결과물을 확인하고 **“추가 수동 정리 없이 실제 콘텐츠 제작에 바로 사용할 수 있다”**고 평가할 것

**최종 판정:** 위 6개 조건을 모두 충족하면 합격으로 판단한다. 하나라도 충족하지 못하면 원인을 기록하고 수정 후 재검증한다.

현재 검증 기준은 시스템 구현 후 적용할 기준이며, 실제 테스트 완료를 의미하지 않는다.
