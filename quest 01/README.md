## 📌 과제 개요
- 첫 번째 퀘스트로 미로 게임(Maze Game)을 직접 만들어 보았습니다.

## 📚 학습 내용
- 코드를 짜기 전에 **PRD(제품 요구사항 문서)**를 먼저 써서 무엇을, 누구를 위해, 어떤 규칙으로 만들지 정해 두는 것이 중요하다는 것을 느꼈습니다.

## 🛠 문제 해결 과정
- 처음에는 캐릭터가 칸 단위로 뚝뚝 끊겨 움직이도록 만들어졌습니다.
- AI에게 부드럽게 움직이도록 다시 만들어 달라고 요청해 수정했습니다.

## 💭 회고
- 게임이 동작하도록 만드는 데는 성공했지만, **디자인 부분이 아쉬웠습니다.**
- 다음 퀘스트에서는 구현 전에 화면 구성과 색상, 레이아웃을 먼저 정리하고 시작해 보려고 합니다.
